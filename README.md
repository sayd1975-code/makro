# Makrocykle L9xx (PRONUM 640FC)

Ściaga i generator programu CNC — makrocykle L90xx sterowania **PRONUM 640 FC**, napisane po frezersku.

PWA — działa offline, można zainstalować na pulpicie telefonu.

## Co umie

- **Mapa zadań** — „chcę zrobić X → wołam Y"
- **Generator** — wpisujesz wymiary, apka klepie gotowy program w N-blokach (kopiuj → wklej na maszynę)
- **Alfabet parametrów R** — uczysz się raz, działa we wszystkich makrocyklach
- **Blokady** — co krzyczy maszyna → co poprawić

Makrocykle: L900, L906, L903, L930, L931, L902, L901, L905, L904 (w tym trik: pełny pierścień R27=1 + R13=360).
